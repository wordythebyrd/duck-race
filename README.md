# 🦆 Duck Race

A highly scientific competitive duck racing simulator. Results may vary. No ducks were harmed.

## What is this?

Configure a field of 2–100 rubber ducks, give them names (or let fate decide), set a race duration, and watch them waddle across a river toward glory. One duck will win. The others will not. Such is life.

Each duck is procedurally accessorized with a random selection of hats, eyewear, neckwear, and the occasional cape. Their racing behavior is governed by a sophisticated physics engine involving speed bursts, sudden slowdowns, brief moments of going backwards, and a generous catch-up mechanic so nobody gets *too* humiliated.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` and may the best duck win.

## Features

- **2 to 100 ducks** — scales from intimate rivalry to absolute chaos
- **Configurable race duration** — 1 second sprint to 5-minute marathon
- **Procedural accessories** — hats, eyewear, neckwear, capes, assigned at random
- **Custom duck names** — or let the name generator handle it
- **Camera system** — follows the leader so you never miss the action
- **Victory podium** — complete with confetti and fireworks for the winner
